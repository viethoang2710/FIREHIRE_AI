Chào mừng đến với dự án FireHire AI

Dự án này được chia thành hai phần: Backend (BE) và Frontend (FE). Chọn một trong các liên kết dưới đây để tiếp tục.

Backend (BE)

Phần BE của dự án được xây dựng với Spring Boot. Bao gồm các API, kết nối cơ sở dữ liệu và xử lý nghiệp vụ cho ứng dụng.

Đi đến Backend

Frontend (FE)

Phần FE của dự án được xây dựng với React. Bao gồm giao diện người dùng, các trang và thành phần tương tác với người dùng.

Đi đến Frontend

Hướng dẫn khởi chạy:

  1. Đọc hướng dẫn chi tiết trong file README.md
  2. Khởi chạy BE (Spring Boot): cd BE && .\mvnw.cmd spring-boot:run (PowerShell) hoặc cd BE && mvnw.cmd spring-boot:run (CMD)
  3. Khởi chạy FE (React): cd FE && npm install && npm start
